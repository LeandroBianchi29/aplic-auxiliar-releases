# APLIC Auxiliar — versões publicadas

Este repositório guarda **somente as versões publicadas (releases)** do APLIC Auxiliar, o programa de apoio à correção dos XML do APLIC Pré-validação (TCE-MT). Não há código-fonte aqui.

- **Baixar:** abra [a versão mais recente](../../releases/latest) e baixe o `APLIC_Auxiliar_Setup.exe` (instalação portátil) ou só o `APLIC_Auxiliar.exe`.
- **Atualizar:** o próprio programa verifica ao abrir (ou pelo botão “Verificar atualização”) e se atualiza sozinho.
- Cada versão traz um `versao.json` com o número da versão, as novidades e o SHA-256 dos arquivos, que o programa confere antes de trocar.

Requer Windows 10/11 com o .NET 8 Desktop Runtime.
